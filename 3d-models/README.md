# 3D Models - QR-Stream Project

Dieses Verzeichnis enthält 3D-druckbare Modelle für verschiedene Hardware-Komponenten des QR-Stream Projekts.

## Verfügbare Modelle

### Euler's Disk Mirror Support
**Verzeichnis**: `euler-disk-mirror-support/`

Ein 3D-druckbarer Support-Inlay für einen konkaven 20cm Grafenspiegel (Euler's Disk). Stabilisiert den Spiegel von unten und verhindert Bruch.

**Dateien**:
- `mirror-support.stl` - Fertig zum Drucken (STL)
- `mirror-support.scad` - Parametrisches Modell (OpenSCAD)
- `README.md` - Detaillierte Dokumentation
- `QUICK-START.md` - Schnellanleitung

**Quick Info**:
- Material: PLA oder PETG
- Druckzeit: ~4 Stunden
- Filament: ~60-80g

## Verwendung

1. Navigiere zum gewünschten Modell-Verzeichnis
2. Lade die `.stl` Datei in deinen Slicer
3. Folge den Druck-Empfehlungen in der jeweiligen README
4. Drucke das Modell
5. Verwende es wie in der Dokumentation beschrieben

## Anpassungen

Alle Modelle sind als parametrische OpenSCAD-Dateien (`.scad`) verfügbar. Du kannst sie mit [OpenSCAD](https://openscad.org/) öffnen und nach deinen Bedürfnissen anpassen.

## Lizenz

Alle 3D-Modelle stehen unter der gleichen Lizenz wie das QR-Stream Hauptprojekt.
